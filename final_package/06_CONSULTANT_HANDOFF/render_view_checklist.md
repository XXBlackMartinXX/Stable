# Render View Checklist & Acceptance Criteria

Use this to accept or reject each render before it is treated as final. A view that fails **any**
box is not a final deliverable.

## Per-view acceptance boxes

For **every** render:

- [ ] Reads as architectural visualization, not a massing/toy model.
- [ ] No visible modelling axes, gizmos, or untextured clay.
- [ ] No stepped-cube / "toy" trees — realistic canopies only.
- [ ] Premium materials present: warm stone/plaster walls, timber stable fronts, metal roofs.
- [ ] Paddocks show textured/raked sand, not a flat colour fill.
- [ ] Paving reads as real stone/grey paving as specified.
- [ ] Soft, directional shadows; ambient occlusion in corners; no blown highlights.
- [ ] Elegant three-quarter composition and lens (35–50 mm equiv; no fish-eye distortion).
- [ ] Layout matches the validated master plan exactly (room count, sizes, positions).
- [ ] No Arabic text burned into the perspective render (labels overlaid in 2D only, if needed).
- [ ] Delivered at required resolution (≥4K per view; hero cutaway ≥5000 px long edge), sRGB.
