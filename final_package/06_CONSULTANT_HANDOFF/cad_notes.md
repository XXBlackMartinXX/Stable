# CAD Notes — `cad_underlay.dxf`

- **Status:** concept underlay only — **not for construction.** The file carries the embedded marking
  `LUXURY EQUESTRIAN STABLE - CONCEPT CAD UNDERLAY ONLY - NOT FOR CONSTRUCTION`.
- **Units:** metres. **Origin:** site south-west corner (0,0). X = east (width, 0–40 m), Y = north
  (depth, 0–50 m).
- **Source:** generated directly from the validated coordinate model; geometry matches the
  dimensioned master plan and schedules exactly.
- **Layers:** organized by room function so a consultant can isolate stalls, wings, paddocks,
  circulation, etc.
- **Intended use:** a coordinated starting reference layer for the licensed design team — trace and
  develop construction documents on top of it; do not treat it as a construction drawing.
- **Also provided for 3D:** `stable_scene.obj` / `.mtl` (this folder) is the import-ready 3D
  equivalent for visualization software.
