# Final Deliverable Index — Luxury Equestrian Stable Redesign

**Concept design package. Ready for licensed architectural/engineering development. Not for
construction or permit use until reviewed and approved by a licensed local architect/engineer,
MEP/civil engineer, and fire/life-safety consultant.**

This is the single folder to hand to a client, reviewer, or consultant: `/final_package`. Every
file in it is a copy of an already-validated deliverable produced by the pipeline in `design/`;
nothing here is a separate or divergent version, and `design/` remains the actual source of truth
and working tree. If `design/scripts/model.py` is ever changed, every file in this folder should be
regenerated by re-running the scripts listed in §2 below, not hand-edited.
