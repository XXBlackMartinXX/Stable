# Luxury Equestrian Stable — Client Handoff

Welcome. This package presents the concept design for a private luxury equestrian stable on a
40 × 50 m (2,000 m²) site. It is organized so you can find what you need quickly.

## Start here

1. **`01_CLIENT_PRESENTATION/`** — the presentation document. Read this first; it walks through the
   vision, the master plan, each zone, materials, and next steps.
2. **`02_HERO_VISUALS/`** — the illustrated master-plan board, the headline visual of the design.
3. **`03_TECHNICAL_DRAWINGS/`** — the dimensioned plan and CAD underlay.

## What this package is — and is not

- It **is** a validated, owner-confirmed **concept design**: a complete room program, a resolved
  layout, exact dimensions, and a premium illustrated master plan.
- It is **not** a construction or permit set, and it does **not** yet include photoreal 3D renders.
  Photoreal visualization is a defined next step, briefed for an external visualization studio in
  `06_CONSULTANT_HANDOFF/` (a clean 3D geometry export and a full render-production brief are
  included).
- Turning this concept into buildable, permit-ready documents requires licensed architectural and
  engineering development — see the gap checklist in `06_CONSULTANT_HANDOFF/`.
