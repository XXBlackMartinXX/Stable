# Render Status

## What is in this folder

- **`01_premium_masterplan_cutaway.png`** — the illustrated master-plan board. This is the
  authoritative visual of the design: a premium presentation drawing generated directly from the
  validated layout, with correct Arabic labels, per-zone materials, entourage, and textured
  paddocks. It represents the design exactly.

## Photoreal 3D renders — status: to be produced externally

Photoreal 3D renders (aerial hero, stable aisle, majlis, paddock, entry) are **not** included here.
They require professional rendering software (Blender/Cycles, Twinmotion, Lumion, Enscape, V-Ray,
or D5), which was not available where this package was produced.

Rather than fill this folder with weak software-massing images, the package provides everything a
visualization studio needs to produce the final photoreal set:

- Clean, import-ready 3D geometry: `06_CONSULTANT_HANDOFF/stable_scene.obj` (+ `.mtl`).
- A full render-production brief, camera schedule, material palette, and acceptance checklist:
  `06_CONSULTANT_HANDOFF/render_production_brief.md` and the accompanying CSV/checklist files.

When commissioned, the finished renders should be delivered back into this folder as
`02_aerial_hero_render.png`, `03_stable_aisle_render.png`, `04_guest_majlis_render.png`,
`05_paddock_courtyard_render.png`, and `06_entry_parking_render.png`.

*This is stated plainly so nothing in this package is mistaken for a photoreal render it is not.*
