## 6. 3D model access

The SketchUp MCP connector's `save_model` tool returns a session-scoped cloud download link, not a
permanent one; this environment's outbound network policy blocks `api.sketchup.com`, so the `.skp`
itself cannot be copied into this git repository (confirmed by a direct `curl` attempt, which fails
with a 403 from the egress proxy). The current download link is recorded in `source_audit.md` §16
and regenerated automatically by `generate_report.py` each time the pipeline runs. A static
thumbnail and aerial render are committed to the repo instead, so the visual result is always
available even after the session-scoped link expires.
