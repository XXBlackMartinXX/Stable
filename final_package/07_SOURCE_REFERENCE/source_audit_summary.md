# Source Reference — Summary

This folder holds the original inputs the design was built from, unmodified:

- **`Requirments.txt`** — the owner's original written program (Arabic).
- **`stable 1.pdf`** — the original dimensioned CAD plan.
- **WhatsApp images** — the original 3D reference render and the hand sketch (site 40 × 50 m, gate
  location).
- **`stable1_page.png`** — a full-page raster of the CAD PDF used during the audit.

Every dimension used in the design traces back to one of these sources or to an explicit,
documented owner decision. The complete source-conflict audit (what each source said, where they
disagreed, and how each conflict was resolved, with confidence levels) is in the technical report:
`05_TECHNICAL_REPORT/` → `source_audit.md` / `technical_appendix.pdf`.
